# K230 独立现场采样程序 v1.5

- 默认 GC2093 1280×720、RGB565 采集、JPEG 质量 90。照片保留原始取景，没有界面、框线或时间戳覆盖。
- 每隔 250 ms 计划取一张。屏幕上选 **5 秒 / 15 秒 / 30 秒**，再按板载用户键开拍（程序使用 GPIO61），分别目标 20 / 60 / 120 张。绿色时长是当前挡位，上电默认 5 秒。持续按住只开拍一次，下次要先松手再按。
- 640×360 实时预览直接送到 LCD，与 720p 保存通道独立。三个时长按钮占满底栏。拍摄时只在距离下一张有余量的情况下更新计数；底栏数字可能延后，结束会显示完整计数。
- 照片在电脑上打开 `data` 分区查看或整理。

## 放到板上

如果上一版连拍程序已经能启动，**只需覆盖 `CanMV → sdcard` 下的 `field_capture.py`**。

1. 把 SD 卡目前能开机的根目录 `main.py` 备份到电脑。
2. 把 `field_capture.py` 放到 `CanMV → sdcard` 根目录。
3. 把 `startup_example.py` 也放到那里，并改名为 `main.py`，替换原来的启动入口。保留 `boot.py`、`ybUtils` 和整个 `car_vision`。恢复识别版只需换回原来的 `main.py`。
4. 独立供电重启。先选 5 秒挡，再按板载用户键（不是复位键），看是否 20/20。可在电脑上打开 `data` 分区放大检查曝光和取景。

照片保存在 `CanMV → data → field_photos → run_0001` 等目录。每次按键新建目录，数字与板载日期无关。文件 `0005_01012ms.jpg` 表示在第 5 个 250 ms 时段开始取帧，相机返回画面的时间是开拍后 1012 ms。若处理太慢，编号可以跳过；相机不会回拍错过的时段。板上显示保存数、每秒保存张数和最长相邻拍摄间隔；串口分别给出取帧与 JPEG 编码加写入的平均和最大用时，以及取帧和文件错误数。

开始前检查 `/data` 至少剩余 512 MiB，写入异常会停止并保留此前照片，不回退到小的 `/sdcard`。采样期间落盘为 `.part.jpg`，最后批量检查并改名，减少两次拍摄之间的目录操作。**屏幕显示「正在整理」时请勿断电**，等显示结束再拔卡。突然掉电后可能留有部分 `.part.jpg`，可在电脑上检查哪些能正常打开。

先验证 5 秒挡是否达到 20/20，再验 30 秒挡（目标 120 张）。若仍漏拍，记录结束后的 `[FIELD]` 串口行；取帧与编码加保存的分段时间能帮助定位。在行驶画面里若有明显拖影，可以增加场地照明或先降低车速。
