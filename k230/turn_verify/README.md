# K230 转弯识别验证版 v1

只检验蓝色圆牌上的白色左、右转弯箭头。屏幕实时预览，底栏显示方向、候选大小、匹配分和识别帧率。确认事件会在串口打印 `[TURN] #1 right ...` 或 `left`。本程序不写照片、不输出给 Ti60。

## 如何上板

1. 把 ZIP 中的 `turn_verify` 整个目录放到 `CanMV → sdcard`，其中有 `field_turn.py` 与三个 `turn_*.py` 辅助文件。保留 `boot.py`、`ybUtils`、现有采样程序及照片。
2. 初次可以在 CanMV IDE 打开 `turn_verify/field_turn.py` 后运行，辅助文件仍需在板上。若要脱离电脑开机运行，备份当前 `sdcard/main.py`，再将包里的 `startup_example.py` 改名为 `main.py` 放进 `sdcard` 根目录。换回备份即恢复连拍程序。
3. 用实际左、右牌各试一次：从远处沿赛道方向慢慢靠近，观察「箭头较小」到显示方向的过程。确认后保持牌子几秒，计数应该只加一次；移出画面后再换另一块牌。最后用蓝方块与停车 P 牌检查是否误报。

### 第一版依据

- 640×360 保持 16∶9；预览和 RGB565 识别用独立摄像头通道。大约每 100 ms 尝试识别一次，实板速度以屏幕为准。
- 用蓝色范围找候选，在候选内找白箭头并与旧版左、右模板比较。短边至少 36 像素，匹配至少 0.60，左右分差至少 0.15，同方向连续 3 次才确认。同框左右冲突会暂缓确认。
- 参考 `现场图片-手机拍的` 中 `IMG_9690.JPG`、`IMG_9698.JPG` 的实际右转位置和大小。`IMG_9705.JPG` 中更远的牌用于验证太小暂不触发；同目录的停车 P 牌、蓝色方块及赛道背景用于检查误报。左侧用先前独立近照（该近照也是模板来源），另对两张现场右转照片做镜像对照。现场照片是手机拍的，不据此宣称 K230 行驶识别率。
- 也用原厂备份中 K230 拍到的 17 张台架照交叉检查：拍屏幕上的箭头识别为两张左转、一张右转，其余 14 张不触发。这组照片不是现场行驶样本。

工作区可用 `python k230/turn_verify/replay_phone_photos.py "现场图片-手机拍的" --bench "原厂固件/car_photos"` 回放，需要 Pillow、NumPy。它共享候选判定和箭头匹配，LAB 与连通域只是对固件的近似，板上仍需验证触发距离和不同光照。
