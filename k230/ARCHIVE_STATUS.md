# K230 v1.6 调试归档（2026-11-17）

本分支保存 K230 前视视觉的调试源码、电脑检查工具和部署说明，基于远程 main 的
`c01bc34` 创建。原工作目录的 main 不变，不在本次归档中合并或修改 Ti60 RTL。

## 已保存的内容

- 左右转箭头模板识别、640×360 等比例预览、640×480 触摸界面。
- 1280×720 人工拍照、标签、场景、连拍及跨会话相册。
- 红绿蓝黄多目标跟踪、向右越线顺序判断、回摆/遮挡/歧义保护。
- SD 自动逐帧测量日志、抽样与关键图片、参数与源码副本、空间保护。
- 电脑端日志分析和 29 项桌面检查。详细部署与数据路径见 [README.md](README.md)。

照片、运行日志、ZIP 包、编译缓存和原厂固件不纳入本次提交。

## 验证边界

用户确认过预览、照片保存与回看；此前 v1.4.5 预览实测约 15～16 FPS。
这些结果不等于 v1.6 的实际运行帧率。v1.6 多目标顺序与 SD 自动记录完成桌面检查，
现场尺寸阈值、行驶扭动、写卡耗时、断电表现和两板联动仍需实机验证。
GPIO_ENABLE 保持 False；不得把桌面检查视作实车或 FPGA 通信验证。

## 与最新 Ti60 接收端的协议差异

**后续更新 v1.6.1（2026-11-17）**：当前工作区已改为匹配 Ti60 的3位数据+STB协议，
固定 DATA=42/43/34、STB=35，不再使用REQ/ACK。下表仅说明归档提交 bb11d00 的历史差异，
不是当前接线依据。当前以 [固定接线](../docs/K230_GPIO_FIXED.md) 为准；GPIO仍默认关闭，待实测。

本次保留已调试的 K230 原型，不擅自更换其通信协议。远程 main 已增加另一种
`src/k230_link.v` 接收方案，两端目前不能直接对接：

| 项目 | 本分支 K230 原型 | 基线 c01bc34 的 Ti60 接收端 |
|---|---|---|
| 时序 | 3 位数据 + REQ/ACK 四相握手 | 3 位数据 + strobe，类别/数值符号分隔，整帧重复两遍 |
| K230 引脚设定 | DATA=42/43/33，REQ=32，ACK=26 | 接收端注释约定 DATA=42/43/34，STB=35，无 ACK |
| 颜色编码 | 3红、4绿、5蓝、6黄 | CAT=1，VAL=1红/2黄/3绿/4蓝 |
| 方向编码 | 1左、2右 | CAT=2，VAL=1左/2右/3直 |

以上只是源码契约对照，不能代替板上自由引脚与电平测量。后续联调需统一协议、引脚、
颜色编码、心跳和重复色事件处理，再启用 GPIO。原型的 ACK 超时不能证明最新接收端失效，
因为该接收端本身没有 ACK 输出。
