# Ti60 赛道避障调试

赛题 3.3.5 和 4.3.2 规定障碍为黑线中央的约 10 cm 立方体，车辆须在障碍中心前后左右各 50 cm 的区域内自主绕行并回到原线，车身不得触碰方块。按赛道图的行车方向，右侧朝向场地内侧。新版使用右侧前向弧线。

## 触发与动作

1. 前方连续三次测得 28 cm 以内时开始低速接近。离方块约 23 cm 时短刹，按最近一次测距和制动期编码器位移计算起弧距离。可用起弧距离约为 19.5～23.5 cm，起点需稳定压住直道。
2. 外摆和摆正各用约 64° 的弧线。轮距 164 mm，轮周长 212 mm，编码器每圈按 2532 计数。内外轮的单弧目标分别为 1094 和 3282 计数。两轮前进为正，各自达到累计目标才切段。领先轮减速或短刹等落后轮。
3. 侧边直行长度根据起弧距离确定，约为 13～17 cm。以 23 cm 起弧为例，侧边段两轮各走约 16.4 cm。完成两轮行程并确认已离开原线，才转入回线。
4. 左弧切回后用右弧摆正。车头约 13 mm 的低速找线余量内，稳定居中压线 35 ms 后交回循迹。障碍标志清除且继续前进约 12 cm 后重新允许触发。

车轮无进度、反向计数、测距失效、转弯或找线超限会停车，重新摆车后按 K1 可重试。K2 可立即停止。普通循迹由原有状态机控制，避障段的轮速修正直接使用有符号的左右轮行程。板上接线以倒车实测的通道和相位为准。

## 串口观察

CH340 使用 115200 8N1。第一行 `M=07` 表示避障接管，`M=04` 表示停车。第二行的 `B` 表示避障阶段，`L/R` 对应实际左右轮，向前为正。

使用 `python bench/serial_tool.py avoid --port COM17 --sec 15` 可以记录阶段切换，串口号按实际枚举填写。

| B | 阶段 |
|---|---|
| 0 | 循迹，等待触发 |
| 1 / 2 | 低速接近 / 刹车等稳 |
| 3 / 4 | 右弧外摆 / 左弧摆正 |
| 5 | 侧边超越 |
| 6 / 7 | 左弧回切 / 右弧摆正 |
| 8 / 9 | 居中确认 / 交还循迹 |
| F | 故障停车 |

## 模型与实车

几何模型按车身长 200 mm、含轮宽 185 mm、驱动轴距车头 75 mm 计算，超声探头位置按车头等效。运行 `python bench/course_bypass_geometry.py` 可复核车身包络与方块间隙。模型用理想滚动，抽查起弧距离、初始偏移和角度变化。实际地面上仍需测量方块间隙、车身是否留在胶带内，以及回线表现。
