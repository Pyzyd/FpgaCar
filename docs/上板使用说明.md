## 2. 串口怎么看

115200 / 8 / N / 1，CH340 通常枚举为 COM12。每 60 ms 两行：

```
D=015cm T=00011000 P=+00 O=0 M=00
L=00000000 R=00000000 VL=0000 VR=0000 X=11100111 C=+000 DL=000 DR=000
```

| 字段 | 含义 | 判读要点 |
|---|---|---|
| `D=xxxcm` | 超声距离，`---` = 无回波 | 静置小幅抖动正常；大面积 `---` 才算故障 |
| `T=` | 循迹压线位图，**首字符是 bit7（最右）** | 1 = 压线。全 1 或全 0 都要查 |
| `P=±nn` | 线位置 -16..+16，正 = 线在右 | 应与 T 的亮位中心大致对应 |
| `O=` | 障碍标志 | **本版恒为 0**（超声、红外均关闭） |
| `M=nn` | 00 IDLE / 01 RUN / 02 LOST / 03 SEARCH / 04 STOP | 见第 4、5 节 |
| `L=/R=` | 编码器累计 | 未装编码器，恒 0 属正常 |
| `VL=/VR=` | 速度 | 未装编码器，恒 0 属正常 |
| `X=` | 消抖后**原始电平**，bit7..bit0 = X8..X1 | **必须与 T 逐位互补** |
| `C=±nnn` | PID 修正量，限幅 ±600 | 车未进 RUN 时恒 0 属正常 |
| `DL=/DR=` | 实际下发占空比（3 位十六进制） | DL=600+C、DR=600-C，600=0x258 |

**最关键一条**：`X=` 与 `T=` 逐位取反。例：`X=11100111` ↔ `T=00011000`。两者相同即为 `ACTIVE_HIGH` 设反。

## 3. OLED 屏上看到什么

上电白闪一下再转黑是自检，随后显示下面五块。**不接串口也能判读。**

| 位置 | 内容 | 说明 |
|---|---|---|
| page0 中部 | `10000001` 八位二进制串 | 自左向右 = bit7..bit0，与串口 `T=` 字符序一致，可逐字对照 |
| page1 | 八根竖条 | 第 1 根 = X1 = 车体最左；压线那路整列点亮 |
| page6/7 左 | 三位数字 + `cm` | 超声距离；无回波显示 `---`，超 999 饱和 |
| page6/7 中 | 一位状态号 | 与串口 `M=` 同值 |
| page6/7 右 | 四格 | 自左向右：障碍 / 左红外 / 右红外 / 丢线；实心 = 置位 |

中间四个 32×32 汉字色块（红绿蓝黄）是颜色顺序显示区，K230 未接时保持空槽。

## 4. 测试流程与通过标准

1. **先架空车轮**（或拔掉电机电源）再上电，串口持续出数 → 链路通。
2. 不压线：`M=00`、`DL=DR=000`、`C=+000` → 起跑安全锁生效（需连续压线 2 s）。
3. 拿黑线在探头下方来回移：`X=`、`T=`、`P=` 连续变化，屏上 page1 竖条跟随 → 循迹链路通。
4. 车压在线上静置 2 s：`M` 由 00 转 01，`DL/DR` 离开 000，`C=` 随偏差变化 → PID 在算。
5. 拿起车（丢线）：`M` 依次 01→02→03，`DL/DR` 停在找线占空比 → 状态机正常。
6. 一直不放回线上：`M` 由 03 回到 **00**（不是 04）→ 本版新行为，可反复测，不必断电。

本版两个现场行为变化：找线失败回 IDLE 而非永久停车；超声不再因 25 cm 内有墙把车摁停（`O=` 恒 0）。

## 5. 常见异常速查

| 现象 | 最可能原因 | 处置 |
|---|---|---|
| 串口无任何输出 | 旧位流 / 烧录失败 / 只开 Ti60 开关而 USB 未枚举 | 重跑 `prog.sh`；查 `pnputil /enum-devices /connected /class Ports` |
| 第二行只有 37 字符 | 板上是旧位流 | 重烧 |
| `X=` 恒 `11111111`、`T=00000000` | 模块看到全黑：压在深色面 / 电位器到底 / 未供电 | 抬离桌面看是否变 `00000000` |
| `X=` 与 `T=` 相同 | `ACTIVE_HIGH` 极性设反 | 改 `src/track_line.v` 参数 |
| `D=---` 占比高 | 超量程或反射面太斜 | 属正常，靠近再看 |
| `DL/DR` 恒 000 但 `M=01` | v1.0 位流的 `dead_cnt` 位宽 bug（v1.1 已修） | 换 v1.1 位流；换完仍 000 就对照 `C=` 是否也 0 |
| 车原地打转不停 | 找不到线，未超 `SEARCH_MS`(1.5 s) | 正常，超时会回 IDLE |

## 7. 版本记录

**v1.1（2026-11-18）** —— 修 `dead_cnt` 位宽 bug。相对 v1.0 只有一处变化：

- 修好「`M=01` 却不走」：`src/car_fsm.v` 的 `DEAD_CYC = MS_DIV * DIR_DEAD_MS` 在 24 MHz、`DIR_DEAD_MS=10` 时是 240000，而计数器只有 16 位（上限 65535），永远数不到头 → 换相死区一旦置位就清不掉，`en` 与 `duty` 恒 0。已改为 32 位。
- 判据：压线 2 s 起跑后，第二行 `DL=`/`DR=` 应在 300~900 之间随偏差变化，不再恒 000。

**v1.0（2026-11-18）** —— 首版，对应「单测循迹」位流。

- 串口新增四项：`X=` 原始电平、`C=` PID 修正量、`DL=`/`DR=` 实际占空比（第二行 37 → 69 字符）。
- 新增 `SEARCH_FAIL_TO_IDLE`：找线超时回 IDLE，可反复测试不必断电。
- 关闭超声障碍判定与 K230（`O=` 恒 0）。
- OLED 补齐全部可见调试量（二进制串 / 循迹条 / 距离 / 状态号 / 四标志格）。
