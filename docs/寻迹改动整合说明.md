# 寻迹（循迹）改动整合说明 —— v1.19 / v1.20 / v1.21

本文把「让小车沿黑线跑稳」这条线上**所有**动过的 RTL 参数与逻辑集中在一处，
方便对照与回退。避障相关的改动不在这里（见 PROJECT_PLAN.md 的 3.51 及之后）。

历史背景：v1.15 用的 P=120 / D=220 是**纯仿真**定出来的（传感器连续、左右轮完全
对称）。实车表现为「线能跟上，但一直在小幅甩，偶尔直接拐出去」。v1.19 起的参数全部
来自串口实测（`bench/serial_tool.py log` 采的 `.scratch/run_track1.csv` 173 个 RUN 帧、
`.scratch/run_track2.csv` 80 个），不是仿真。

---

## 1. 三个根因（实测定量）

### 1.1 传感器是台阶量化的，pos=0 几乎不存在

8 路探头间距 11 mm、线半宽 6.5 mm：

| 压线情况 | 窗口宽度 | 说明 |
|---|---|---|
| 只压 1 路 | **9 mm** | 绝大多数时间 |
| 内侧两路同压 | **2 mm** | `2×6.5 − 11` |
| pos=0 | 仅 cnt==0 时 | `src/track_line.v:212-215` 把 wsum=0 判成正 |

实测 RUN 帧的置位数分布 `{1: 153, 2: 18, 3: 2}` —— **88% 只压 1 路**，`pos` 只能取
±1/±3/±5/±7（奇数占 89%），`pos=0` 全程只出现 1 次。相邻探头切换 **Δpos=±2**，
乘 `D_GAIN=220` 就是 **440 计数**，一个人就能顶满 ±480 的钳位。

`bench/flick_scan.py`（加 20% 概率 pos±1 抖动）量化了后果：`P120/D220` 在 32 秒内
修正量符号翻转 **1731 次**，`P120/D40` 只翻 **11 次**。D 项在实车上完全被量化噪声主导。

### 1.2 真正的稳态误差是左右轮不等，而积分权限只有 20

实测稳态反复出现 `DL=340 / DR=620`（指令半径 `R = WB(dl+dr)/(2(dr−dl))` = +274 mm），
但**实测曲率反号**（R = −362 ~ −477 mm）。硬边界推导不依赖任何标定：
`dr/dl = 620/340 = 1.82` 却仍有 `dR < dL`，故 **K_R/K_L < 0.548**；而 t=9.2~11.1 s
实测 R=−4366（几乎直线）说明该点正是配平点 → **K_R ≈ 0.55 K_L**。

直行所需偏置因此约 **−147**。但 `src/track_pid.v` 的 `I_LIMIT=640`、`I_SHIFT=5`
只给积分 **640>>5 = 20** 的权限，且每拍只累加 `pos`（±1 量级），要爬几千拍 —— 实际
永远爬不上去。证据：稳态帧（前后帧 P 与 C 都不变）44 个，`i_term = C − P×120`
**全部等于 −20**，100% 顶死。

于是只能靠「主动偏一格」凑：`pos=−1` → `−120`，加积分 −20 = **C=−140**，正好对上
实测 C 中位 −140。代价是工作点卡在悬崖边：`pos` 从 −1 跳到 −3 就是 C 从 −140 到
−380（Δ240），跳到 +1 是 +100 —— **中间没有档位**，这是 C 每 300 ms 翻符号 45% 的根源。

### 1.3 速度同步环在实车上从来没有生效过

v1.17 给 `speed_pid` 加了 `SYNC_DIFF_MAX=120` 门控（只要大差速就直通）。但门控判据是
`cmd_diff = |ctrl_l − ctrl_r| = |2C|`，而 C 常态就在 ±140~±480：

| | 中位 | ≤120 的帧 |
|---|---|---|
| run1（173 帧） | 280 | **0 / 173** |
| run2（80 帧） | 280 | **0 / 80** |

用正确公式 `sum_lim = (DR−DL)/2 + C` 反解，**91% 的帧速度环输出恰好为 0**。

而且就算把门控放开方向也是错的：配平点 `DL=340/DR=620` 上两轮实测本来就等速、
曲率≈0，同步环若强拉平，等于把这个「偏占空比换直行」的配平点当误差修掉 —— **禁止转弯**。

## 2. 改动一：`src/track_pid.v` 新增 TRIM 前馈

```verilog
parameter integer TRIM = 0           // 前馈偏置（抵消两轮效率差）
```

求和项从 `p_term + i_term + d_term` 改为：

```verilog
wire signed [15:0] f_term  = TRIM;   // 整数赋 16 位 signed 自动符号扩展
wire signed [15:0] sum_raw = f_term + p_term + i_term + d_term;
```

公式变成：

```
corr = TRIM + pos*P_GAIN + (i_acc >> I_SHIFT) + (pos − pos_d)*D_GAIN
```

**推导**：令两轮等效每占空比速度 `K_L`（左）、`K_R`（右，约 0.55 K_L）。直行要求
`K_L·(BASE+c) = K_R·(BASE−c)`，解得

```
c = −BASE · (1 − 0.55) / (1 + 0.55) ≈ −140
```

**为什么必须做前馈而不是放大积分**：积分权限只有 20，而需要的是 140 —— 差 7 倍。
把 `I_LIMIT` 提到 8192 也能爬到 140，但那是「用几秒钟的积分过程去补一个静态偏差」，
过程中车已经偏出线了。前馈是一上电就到位，积分只剩补残差。

**放钳位之前**：`sum_raw` 之后再钳 `±BASE`，这样 TRIM 占掉的那部分量程不会被钳位削掉
（放钳位之后两者在实车上完全等效，选之前是因为量程解释更清晰）。

## 3. 改动二：增益 P120/D220 → P80/D30

| 参数 | v1.15 | v1.19 | 依据 |
|---|---|---|---|
| `P_GAIN` | 120 | **80** | P 决定「一格偏差给多少修正」；Δpos=2 时 80×2=160，仍在合理差速内 |
| `D_GAIN` | 220 | **30** | 220 在量化噪声下每秒翻转 1731 次；30 只剩 11 次 |
| `I_SHIFT` | 5 | 5 | 不动，积分只补残差 |
| `I_LIMIT` | 640 | 640 | 不动（trim 已补偿静态量，容量不再是瓶颈） |
| `TRIM` | — | **−140** | 见上节推导 |

选型来自 `bench/gain_final.py`（140 组：R=4000/600/400/300/240/200/160 × dp ±15/±8/0 ×
flick 0/0.20 × seed 1/2）：

| 配置 | 失败 | worst | rms_med |
|---|---|---|---|
| P120 D220 TRIM=0（现状） | 0/140 | 10.1 | 8.02 |
| P80 D30 TRIM=−140 i640 | 0/140 | **6.5** | **0.95** |
| P80 D20 TRIM=0 i8192（纯积分自适应） | 0/140 | 9.8 | 1.01 |

**注意**：仿真里几乎所有配置都不「失败」，因为理想传感器复现不出实车的失稳机制
（量化台阶 + 积分顶死 + 速度环被门控关死）。所以决策看的是 rms 与翻转次数量级，
不是 Y/N。

TRIM 灵敏度（`bench/gain_trim_sens.py`，P80 D30）：trim 0→rms 9.20；−60→3.88；
−100→1.87；−120→1.28；**−140→0.95**；−160→0.79；−180→0.73；−220→1.55；−260→6.46。
且 KR=0.140~0.210 全范围下 trim=−140 都是 0 失败 → **trim 不需要精确值，稳健**。

## 4. 改动三：关闭速度环

`src/FpgaCar.v:192`：

```verilog
localparam SPEED_LOOP_EN = 1'b0;   // v1.19 起关闭（原 1'b1）
```

速度环模块与接线**全部保留**（`speed_pid` 例化、`.SYNC_DIFF_MAX(120)` 都在），只把开关
置 0。理由见 1.3：门控从未放开，且方向与「差速转向」本质冲突。

恢复方法：把该 localparam 改回 `1'b1`。

## 7. 上板后怎么调（如果直道仍偏）

按这个顺序，一次只动一个：

1. **先动 TRIM**：直道持续朝一侧偏就调 `TRIM`，每步 ±20（−140 → −120 或 −160）。
   调到「直道上 C 的均值接近 0」为止。
2. **再动 D**：快摆（车头左右抖）就把 `D_GAIN` 从 30 加到 40~50。**不要拉回 200**，
   那是量化噪声的放大器。
3. **最后动 P**：跟线吃力（弯道内侧切不进去）就把 `P_GAIN` 从 80 加到 100。
