# 现场整合版

## Ti60

用 Efinity 打开本分支根目录的 `FpgaCar.xml`。工程已包含 `course_finish.v`，使用现有 `FpgaCar.peri.xml` 接线。保存修改后，从 Efinity 运行综合、布局布线和位流生成，生成文件在 `outflow/`。

顶层 `src/FpgaCar.v` 里搜索 `手动调参区`。现场保持 `PARKING_DEBUG=0`，K230、超声波、OV5640 后视找库、ST7789 取景和 OLED 色序同时可用。E18 冗余红外与独立拍照相册沿用各自的接线与台架配置。

| 参数 | 初值 | 含义 |
|---|---:|---|
| `TRACK_P_GAIN` / `TRACK_D_GAIN` | 64 / 24 | 循迹 P / D，保留主线的 D 项低通和限幅 |
| `TRACK_TRIM` | +34 | 左右轮配平，正值提高左轮 PWM 并降低右轮 PWM |
| `TRACK_BASE_DUTY` | 384 | 居中时左右轮平均 PWM，周期为 1200 |
| `TRACK_SPEED_PERCENT` | 100 | 常规循迹相对当前主线的比例，当前主线基础 PWM 已为 384 |
| `PARK_AFTER_P_PERCENT` | 85 | 收到 P 后相对常规循迹的比例 |
| `PARK_AFTER_CORNER_PERCENT` | 50 | 检出库角后相对常规循迹的比例 |
| `POST_PARK_PERCENT` | 70 | 出库回线后相对常规循迹的比例，终点直行也用这档 |
| `START_BOX_MM` | 400 | 从 K1 起按双轮平均净里程划定起步区，区内宽横线按居中通过 |
| `FINISH_MIN_SENSORS` / `FINISH_CONFIRM_MS` | 6 / 8 | 终点横边最少持续压黑的探头数和毫秒数 |
| `FINISH_MM` | 300 | 终点横边确认后继续直行的毫米数 |

## K230

把 `k230/field_startup.py` 复制到 SD 卡根目录并命名为 `main.py`。把以下运行文件放进 `car_vision/`，三个转向识别文件保留在 `turn_verify/` 子目录。保留已有 `boot.py` 和采样数据。启动后控制台显示 `FpgaCar-field-integration-v1` 与 `GPIO: True`。

```text
main.py
car_vision/
  field_vision.py  config.py  color_detector.py  color_core.py
  arrow_core.py  arrow_templates.py  multi_tracker.py  gpio_link.py
  album.py  run_recorder.py  parking_detector.py
  turn_verify/
    turn_detector.py  turn_shape.py  turn_templates.py
```

P 确认后通过原 DATA42/43/34 与 STB35 发 `CAT=011, VAL=011`，Ti60 收到两份一致的消息才进入找库。颜色和箭头沿用原编码。实物线序见 [GPIO 接线表](K230_GPIO_FIXED.md)。

## 赛道顺序

1. K1 起跑。起步区的框横边只影响短暂的直行控制。八路红外继续循迹，K230 传方向、颜色和 P，超声波负责每轮一次避障。
2. 收到 P 后减速，侧视相机先找库角，再用双角的中点触发停车。接着左转、直倒 30 cm、停约 5 秒、直行出库并右转回线。
3. 归线后以低速循迹，启用终点横边判断。确认横边时记录两轮编码器位置，以平均净里程继续直行 300 mm。制动时延和轮胎打滑会影响实际停车位置，现场可调整 `FINISH_MM`。
4. 末段直行时 ST7789 状态条为橙色，停止后为红色。K2 随时撤掉驱动。终点的探头阈值和确认时间需按进框实测核对。
