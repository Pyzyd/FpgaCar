# 小车使用说明

适用于 Ti60 的 K1/K2 按键版与 K230 的现场前视版。Ti60 用八路红外循迹并控制电机，K230 识别左右转牌与四色方块。
**当前版本 v1.12（2026-11-23）**，对应位流 `outflow/FpgaCar.bit`。上板调试与参数见 [上板使用说明](上板使用说明.md)。

## 上车操作

1. **通电检查**。首次试车先架空车轮，再给 Ti60 和 K230 供电。Ti60 的 OLED 白闪后，page 0 左侧应出现实心方块（存活标记），顶部一行显示 `ST:IDLE LOST:0`。K230 通信正常后，page 0 右侧的 `×` 会消失。
2. **摆车**。把八路红外探头摆在起点黑线正上方。OLED 的 `LN:` 一行应能看到 `1`。首次安装或调整探头高度后，用场地黑线和白底校准 YB-MUX04。 [循迹模块接线与校准](模块接线说明.md)
3. **开始**。短按 Ti60 核心板的 **K1**。压在线上时状态变 `ST:RUN `，车开始循迹。
4. **停车**。短按 **K2**，Ti60 关闭电机驱动，OLED 显示 `ST:STOP` 并保留已记录的色序。继续本轮时，先把车摆回线上，再按 K1。停车后车轮可能因惯性短暂滑行。
5. **重新跑一轮**。按住 **K2 约 1 秒**，等四色格清空、状态回到 `ST:IDLE` 后松手。重启 K230 的前视程序，使它也重新记录本轮色序。相机预览出来、右上角 `×` 消失后再按 K1。

**K3** 会让 Ti60 从板载 Flash 重新配置并回到待机，Ti60 屏上的色序随之清空。K1、K2 与 P4 的 2、1 脚复用，这两根排针留空。 [引脚分配](引脚分配表.md)

> **按了 K1 车却不动**：多半是那一刻探头没看到黑线。面板这时进的是 `LINE` 状态（内部锁定，不允许起跑），但屏上 `ST:` 显示的仍是 `IDLE` —— 因为 `ST:` 报的是状态机状态，只有按 K2 停车才会被强制改显 `STOP`。处置：把车摆到线上，松手后再短按一次 K1，看到 `ST:RUN ` 才算起步。

## OLED 怎么看

屏幕分四块：顶部一行状态、中间四个色块、底部两行调试数据，四角是存活/掉线标记。

| 位置 | 显示 | 含义 |
|---|---|---|
| page 0 左 | 实心方块 | 固件在跑（存活标记，随帧翻转）。看不到就是 OLED 链路断了 |
| page 0 右 | `×` | Ti60 暂时未收到 K230 的有效通信（2 s 无合法消息） |
| 第一行 | `ST:IDLE LOST:0` | 状态名 + 是否丢线，见下表（恰好 16 字符，行尾补两空格） |
| 中间四格 | 红、绿、蓝、黄 | 从左到右显示本轮登记次序 |
| 倒数第二行 | `DIST:025 CM OB:0` | 超声距离（cm），`---` = 无有效回波；`OB` = 障碍标志 |
| 最后一行 | `LN:00011000 TR:L` | `LN` 是八路压线位图，**首字符是车体最右的 X8，末字符是最左的 X1**（与串口 `T=` 同序）；`TR` 是最近转向方向 |

`ST:` 状态名对照：

| 显示 | 含义 |
|---|---|
| `IDLE` | 待机。上电后、清空后、或按 K1 时没压线都停在这里 |
| `RUN ` | 本轮已启动，正在循迹。短时找线期间也可能还是 RUN |
| `LOST` | 刚丢线，短暂保持上一拍动作（300 ms） |
| `SRCH` | 原地找线，最长 1.5 s |
| `STOP` | 已按 K2 停车，或找线超时、绕障受阻、回线失败 |
| `A-BK` / `A-TN` / `A-PB` | 避障流程：后退 / 转身 / 试探（五段弧绕行时依次经过） |

`LOST:` 与 `OB:` 分开显示，一眼能分清「没线」还是「被挡」。

## 现场排查

| 现象 | 检查方法 |
|---|---|
| 按了 K1 车不动、`ST:` 仍 `IDLE` | 按 K1 那一刻没检测到黑线，面板进了 `LINE` 锁停。摆回线上再按一次 K1 |
| `LN:` 全 `0` 但探头压在黑线上 | 检查供电、探头高度和 YB-MUX04 校准（模块无电位器，靠板上 key1 自动校准） |
| 右上角长时间显示 `×` | 确认 K230 已运行前视程序，再核对 DATA0、DATA1、DATA2、STB 和共地 |
| 清空后下一圈始终录不到色块 | K2 长按清的是 Ti60 上的色序。每轮开始前还需重启 K230 前视程序 |
| 看到转弯牌时车直行 | Ti60 会先记住方向，等红外检测到宽黑线并随后丢线才转。若经过岔口仍无转向，查 K230 识别与 `TR:` 字段 |
| 避障转出后 `LOST:1` | 小车固定从障碍右侧绕行。侧绕期间八路离线是预期现象。绕过障碍后反向画弧切回，**扫到线即停**，最多转 1.6 s |
| 绕障后一路找不到线、最后 `ST:STOP` | v1.9 前的位流是定长转 650 ms，电池电压/地面摩擦一变就转不到位。v1.9 起改为扫线闭环（`AVOID_TURN_IN_MS` 只作上限，2026-11-20 提到 1600 ms，出线转向同时由 800 提到 1000 ms）。若仍找不回，说明绕行时车头已偏太多，查 `AVOID_PASS_MS` 是否太长 |
| 菱形锐角转弯后丢线 | v1.10 前牌转向是定长 700 ms，锐角所需转角更大。v1.10 起改成闭环：先转够 250 ms，之后连续 20 ms 压回线就收工，`TURN_MS` 提到 1100 ms 只作上限。不够就继续加大 `TURN_MS`——闭环会自己提前结束，加大上限没有副作用 |
| 车跑起来两个轮子明显不齐 | v1.12 起有速度环（`SPEED_LOOP_EN=1`），靠编码器自动拉平两轮。若编码器没接，1 s 后自动直通，恢复到纯开环 |
| 直道上也显示 `TR:L` / `TR:R` | 正常。`TR:` 表示「1.5 s 内转过哪边」，不是此刻正在转，超时自动回 `-` |
| OLED 有显示，车不动 | 先看 `ST:` 是 `IDLE` / `STOP` 还是 `RUN `。若已 `RUN ` 且车轮确认可转，再查 TB6612 的电机供电和接线 |

### 彩屏预览（ST7789，2026-11-20 起）

从这一版起，小车固件本身带彩屏输出，不用再单独烧 bench/st7789 的独立工程。屏接 P4 的 35/36/37/38/40 五根针，供电用外部 3.3 V 并与 Ti60 共地。

| 现象 | 说明 |
|---|---|
| 屏全黑、无背光 | 先查屏的 VCC 和背光。背光常亮，有背光但黑屏说明数据没到 |
| 有背光、一直白屏 | 初始化没完成或 SPI 没通。检查 5 根线，尤其 CS 是否接在 40 针（39 针被 K230 的 STB 占用） |
| 出画面但很卡 | 正常。6 MHz SPI 下一帧约 0.2 s，约 5 帧/秒 |
| 画面是黑白的 | 正常。当前是摄像头灰度预览转 RGB565，偏绿是因为 G 通道多一位，不是配置错 |
| 画面上下颠倒或左右反 | MADCTL 扫描方向问题，改 `src/FpgaCar.v` 里 `u_lcd` 的 `.MADCTL` |
| 花屏、闪烁、条纹 | SPI 太快。把 `LCD_SPI_HALF_CYCLES` 从 2 改回 4（一帧 0.41 s） |

预览与颜色识别互斥：开着预览时 `cam_color` 恒 0，颜色仍由 K230 提供。

台架联调可先断开电机电源，用黑线或黑纸让探头读到 `1`，确认屏上依次看到 `IDLE` → `RUN ` → `STOP`。再长按 K2，确认回到 `IDLE`。 [电机与传感器接线](模块接线说明.md)、[K230 固定通信线束](K230_GPIO_FIXED.md)
