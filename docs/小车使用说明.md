# 小车使用说明

适用于 Ti60 的 K1/K2 按键版与 K230 的现场前视版。Ti60 用八路红外循迹并控制电机，K230 识别左右转牌与四色方块。

## 上车操作

1. **通电检查**。首次试车先架空车轮，再给 Ti60 和 K230 供电。Ti60 的 OLED 白闪后应显示 `READY`，K230 应显示前视预览。K230 通信正常后，OLED 右上角的 `×` 会消失。
2. **摆车**。把八路红外探头摆在起点黑线正上方。OLED 上排的八位数字里应能看到 `1`。首次安装或调整探头高度后，用场地黑线和白底校准 YB-MUX04。 [循迹模块接线与校准](模块接线说明.md)
3. **开始**。短按 Ti60 核心板的 **K1**，OLED 显示 `RUN`，车开始循迹。若显示 `LINE`，把车重新摆到线上，松开 K1 后再短按一次。
4. **停车**。短按 **K2**，Ti60 关闭电机驱动，OLED 显示 `STOP` 并保留已记录的色序。继续本轮时，先把车摆回线上，再按 K1。停车后车轮可能因惯性短暂滑行。
5. **重新跑一轮**。按住 **K2 约 1 秒**，等 OLED 回到 `READY`、四色格清空后松手。重启 K230 的前视程序，使它也重新记录本轮色序。相机预览出来、右上角 `×` 消失后再按 K1。

**K3** 会让 Ti60 从板载 Flash 重新配置并回到待机，Ti60 屏上的色序随之清空。K1、K2 与 P4 的 2、1 脚复用，这两根排针留空。 [引脚分配](引脚分配表.md)

## OLED 怎么看

| 位置 | 显示 | 含义 |
|---|---|---|
| 上排数字右边 | `READY` | 上电或清空后的待机。车摆在线上后短按 K1。 |
| 上排数字右边 | `RUN` | 本轮已启动。短时找线和绕障期间也显示 `RUN`。 |
| 上排数字右边 | `STOP` | 已按 K2 停车，或找线超时、绕障受阻或回线失败。恢复时重新摆车并按 K1。 |
| 上排数字右边 | `LINE` | 刚才按 K1 时探头没检测到黑线。 |
| 上排左侧八位数和下方条带 | `0` / `1` | `1` 表示该路看到黑线。条带左端对应车体最左的 X1。 |
| 右上角 | `×` | Ti60 暂时未收到 K230 的有效通信。 |
| 中间四格 | 红、绿、蓝、黄 | 从左到右显示本轮登记次序。 |
| 最底部 | 距离、状态号、四格 | 距离单位为 cm，`---` 表示无有效回波。四格从左到右为障碍、丢线、左转、右转。 |

## 现场排查

| 现象 | 检查方法 |
|---|---|
| 按 K1 显示 `LINE` | 看八位数字能否从全 `0` 变成部分 `1`。如果探头压在黑线上仍全 `0`，检查供电、探头高度和 YB-MUX04 校准。 |
| 右上角长时间显示 `×` | 确认 K230 已运行前视程序，再核对 DATA0、DATA1、DATA2、STB 和共地。 |
| 清空后下一圈始终录不到色块 | K2 长按清的是 Ti60 上的色序。每轮开始前还需重启 K230 前视程序。 |
| 看到转弯牌时车继续直行 | Ti60 会先记住方向，等红外检测到宽黑线并随后丢线才转。若经过岔口仍无转向，查看 K230 识别和底部左右转格。 |
| 避障转出后显示丢线 | 小车固定从障碍右侧绕行。侧绕期间八路离线是预期现象。绕过障碍后车向左转，**边转边找线**：一压到黑线就停在当前角度，最多转 1.6 s。若前方持续受阻或回线超时，屏幕显示 `STOP`。 |
| 绕障后一路找不到线、最后 `STOP` | v1.9 前的位流是定长转 650 ms，电池电压/地面摩擦一变就转不到位。v1.9 起改为扫线闭环（`AVOID_TURN_IN_MS` 只作上限，2026-11-20 提到 1600 ms，出线转向同时由 800 提到 1000 ms、转向占空比 540 提到 620）。若仍找不回，说明绕行时车头已经偏太多，检查 `AVOID_PASS_MS` 是否太长。 |
| OLED 有显示，车不动 | 先看 `READY`、`LINE` 或 `STOP`。若已显示 `RUN` 且车轮确认可转，再检查 TB6612 的电机供电和接线。 |

台架联调可先断开电机电源，用黑线或黑纸让探头读到 `1`，确认屏上能依次看到 `READY` → `RUN` → `STOP`。再长按 K2，确认回到 `READY`。 [电机与传感器接线](模块接线说明.md)、[K230 固定通信线束](K230_GPIO_FIXED.md)
